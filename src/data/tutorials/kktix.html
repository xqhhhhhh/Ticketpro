三、插件使用教程

平台语言用英文

捡漏模式

url输入如下商品页页面的url，然后点击启动之后他会自动跳转到选座页面

插件里可以配置type，也就是下图中的比如VIP，ZONE A；如果不填写的话就是默认都可以；如果输入的话就可以限定某些type，先输入的优先级最高

如果有可选的座位的话插件会自动勾选好，然后进入下一步，锁到票之后会持续发出声音，提醒你付款；如果没有可选座位的话，会自动一直刷新，直到有座位。

有些情况会需要输入问题回答才能选座，当前插件已经介入了大模型来回答问题，当然有些问题需要个人信息目前无法回答，出现这种情况的话可以设置模型无法回答时的消息提醒手动输入

接管模式

接管模式主要是针对选座页的，提前开启，到达选座页后会自动接管后续操作。一般公售之类的可以用这个模式，或者手动进入到选座页在开启这个模式。

2.Telegram Bot

  • Search BotFather in telegram
  • Send ‘/start’ and ‘/newbot’ and choose the name of the bot.And it will give you a 'Use this token to access the HTTP API:[你的凭据]' like this one. It is Telegram Bot Token
  • In order to activate the bot , you need to send a message to your bot （not the BotFather）after you get the Token.
  • To get Telegram Chat ID,you should search in you browser 'https://api.telegram.org/bot<your Token>/getUpdates' replace the '<your Token>' by you Telegram Bot Token. And the id （not update_id） below is just the Telegram Chat ID
  • To verify the configuration is correct, you can find an available seat and see whether the telegram bot send message to you

常见问题：

1.BotFather会让你命名机器人，随便命名就可以； Telegram Bot Token是从BotFather处获取的，类似于[你的凭据]（这个是我的值，你们的是你们自己显示的）

2.创建好你的Bot之后，你需要发消息给这个Bot，而不是BotFather，从而激活你的Bot

3.下一步获取Telegram Chat ID，这个不是BotFather发给你的，是要去网页端，在网址里面输入才能够获取，如下图所示，如果你输入正确的话，会显示ok：true，否则为false

4.只显示了ok：true，result：[] ；那就说明你的网址输入没问题，但你的bot还没成功激活，你需要给你的bot随便发几条消息激活一下它；然后就可以获取如下图所示的返回结果了；其中我们要的Telegram Chat ID是下方显示的id，即8397571358这个值（这个是我的值，你们的是你们自己网页显示的），而不是update_id

3.多开浏览器：chrome多账号运行——浏览器多开：

这是一个很万金油的方法，有的时候插件无法正常运行是因为浏览器的缘故，通过这个方法可以新打开纯净的浏览器，所以很多时候新开一个浏览器，在这个浏览器中导入插件（因为是全新的，所以得重新导入插件，输入原来那个激活码即可），就可以解决很多问题

大家如果需要开多个账号一起运行的话需要进行账号隔离（在一个窗口内打开的itp都是一个账号的），点击chrome个人头像，然后选下面的其他chrome个人资料出，点击不同的用户，比如下图中，如果我点击‘用户1’，他就会打开一个和我当前ga这个用户完全隔离的chrome浏览器；同理，你可以创建多个不同的窗口/无需登陆chrome账号

查看是否隔离成功：

浏览器链接中输入chrome://version，查看个人资料路径/Profile Path是否不同

如下图所示，两个个人资料路径的最后分别为Profile 1和Profile 2，则表示完全不同的两个浏览器

如果上述方法没法隔离开，可以在终端中输入
