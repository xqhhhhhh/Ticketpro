三、使用教程

大家银河平台语言用简体中文

捡漏模式

整体逻辑是输入商品页的url，然后点击插件的启动，插件就会自动从商品页开始自动运行，然后选择你配置里填写的场次、票价类型，购买数量、然后自动点击立即购买，之后自动勾选相关须知，锁票；如果没有满足要求的票的话就会自动刷新页面（刷新间隔可以自定义，即区域售罄重试间隔）；然后也可以设置一轮运行的上限时长，即单次循环上限，到达这个时间后，会自动再从商品页开始进行运行；直到有空位并锁上。锁到票的话电脑会持续发出滴滴滴的声音、钉钉也会收到消息，以此提醒用户在5min内进行付款。

抢票模式

抢票模式的原理是插件识别到当前进入到了选场次、选票价类型的那个界面后，会自动进行接管，并进行后续操作；即根据配置选座位，没有座位就自动刷新找座位，直到选到票

抢票模式有一个自动刷新商品页并点击立即购买

这个功能不开启的话，需要你手动进入排队界面，更推荐这样做其实，如果你只开了一个窗口的话；如果开启的话他会自动识别当前按键是否可点击，不可点击的话就按照刷新间隔刷新界面，直到按键可点击，然后自动点击进入排队

插件不涉及排队，需要用户手动点击排队，之后进入到这一步后会自动接管。

所以相对于手动操作，抢票模式的优势主要是选取相关信息、点击按键上会更快一些，而不是说可以提快或者绕过排队

目标场次可以输入多个场次的信息，输入多个则按照你输入的顺序优先级进行选择，也就是说如果你输入的这些场次都有空位的话，就会优先选择顺序靠前的场次；如果留空，则表示默认全选。

票价类别为包含匹配，也就是说下面的话，一般建议填写全部信息，要第一个场的话，就填‘VIP (HK$ 1688.00)’，当然如果你不太确定详细信息的话，填写‘VIP’也是可以的，同理填写1688也可以（如果有多个场信息包含VIP，那这样做，这些多个场都会被包含）

一般大家提前知道的是票的价格，只输入数字即可，比如下面这种情况，我提前只知道这三种票价，我只要前两种，那我配置里输入 1688；1188 然后回车即可

场次切换间隔表示进入选座页后，如果设置了多个场次或者默认不填写，插件会在不同的场次间切换，进入两个场次之间的间隔即为场次切换间隔；如果只设置了一个场次，那这个场次切换间隔就表示刷新间隔

当前默认是1，但这个平台会检测短时间内的请求数量，所以如果是抢票的话，这个切得快一点抢到概率会大一点；但如果是捡漏的话，建议大家把这个值调大一些，比如5之类的

单次循环上线表示一次在选座页停留的时长，主要是为了防止捡漏的时候，一直呆在里面可能引起的可能存在的问题（虽然目前还没发现），所以设置了一个上限，到达这个时间上限后，插件会自动退出到商品页，然后重新再进入进入下一轮循环；如果想一直呆在选座页刷的话这个值设置0就可以

如果选择快递取票，需要提前设置好默认地址

钉钉消息配置

主要是用于锁到票时，人不在电脑边上，就算电脑发出了声音也听不到的情况；如果人就在电脑前就没什么必要弄这个了。具体如何配置可跳转下方链接，这个教程里面有讲（偷懒一下）

钉钉消息只是进行消息提醒，对于插件功能没有任何影响，所以是否接入取决于你们自己

Telegram Bot

  • Search BotFather in telegram
  • Send ‘/start’ and ‘/newbot’ and choose the name of the bot.And it will give you a 'Use this token to access the HTTP API:[你的凭据]' like this one. It is Telegram Bot Token
  • In order to activate the bot , you need to send a message to your bot （not the BotFather）after you get the Token.
  • To get Telegram Chat ID,you should search in you browser 'https://api.telegram.org/bot<your Token>/getUpdates' replace the '<your Token>' by you Telegram Bot Token. And the id （not update_id） below is just the Telegram Chat ID
  • To verify the configuration is correct, you can find an available seat and see whether the telegram bot send message to you

远程控制与支付

有的时候人不在电脑边上，但也有可能刷到票；这种情况的话可以手机和电脑上装一个免费的todesk或者向日葵，从而实现手机远程操控电脑；这样的话人在外面，刷到票后手机会收到消息提醒，然后远程操控进行付款即可
