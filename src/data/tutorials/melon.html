d.选座模式-选座模式如何填写——自定义区域/自定义座位/小场座位

首先，两种模式是二选一的，如果你只是想要某些区域中的位置的话，选自定义区域即可；如果你希望指定某些区域的行、某些区域的列，或者某些区域的指定座位的话，可以使用自定义座位

自定义区域：

需要严格遵循大小写

区域功能会根据你填写的区域的顺序循环查找空余位置，如果一个区域内有多个位置，会优先选取更靠前的、更靠中的座位。

简而言之，每个区域需要填两个值，一个是Floor后面的那个值，一个是Sec后面的那个值

以下图为例，图片中第一行区域需要填写 Floor,A ，像图中第三行区域填写1,B1。每填写完一个可以按回车添加；也可以1,C3；2,A4；Floor,A这样用分号进行分隔，按回车批量添加。

官方在开票前会放下方这种区域图，我们可以通过这个图提前获取区域信息，内场就是Floor,we;Floor,are;Floor,one;Floor,EXO看台就是 1,1;1,2等等 二楼就是2,24;2,25等等

如果区域号里面有爱心的话，或者其他乱七八糟的符号，可以按如下操作复制：
1.右键你要的区域，点击检查

2.右侧viewGradeZone中的值，复制出来粘贴到区域选择栏，按回车即可添加

有些场的Floor可能是空的，比如直接显示Sec 1，这种情况楼层号留空 ，输入 ，1即可（逗号+号码，即楼层留空）

如果是韩版：下面的区域填写即为英文与阿拉伯数字，不用管韩文。 Floor,H;Floor,I;Floor,S;Floor,W;1,3;1,4;1,5

自定义座位：

比较复杂，建议先看视频教程！

需要严格遵循大小写

自定义座位可自定义行/列/具体座位 多个集合的话，取并集

在这一步，每个座位都需要有4个属性，即楼层、区域、X、Y。

  • 楼层、区域选择和上面的自定义区域教程完全一致；
  • 至于X、Y，这两个值是可以为空，也可以填写具体值的。
  1. 如果X、Y均为空，比如填写“2,C3,,”，这表示2层C3这个区域都可以
  2. 如果X为空，比如“1,C3,,1366.2”，那这就表示你只想要1楼C3区域Y=1366.2这一行
  3. 如果Y为空，比如“1,C3,1366.2,”，那这就表示你只想要1楼C3区域X=1366.2这一列
  4. 如果X、Y均填写，那就是指定座位，比如 “1,C3,1366.2,740.1”表示要1楼C3区域X=1366.2，Y=740.1这一具体座位

3.间隔参数设置

切区过快会经常please try again，melon点击这个弹窗确定后会回到座位图首页，所以会影响效率，所以我们虽然可以自动点击这个确定，但还是要尽量减少其出现；这主要通过调大切换区域间隔的值来实现；为了不让每次切区都是一个间隔，所以可以加随机抖动范围，如下图，每次切换区域的间隔是3000～4000的一个随机值；锁座反应延迟越小，会锁得越快，也就不太容易被别人抢先一步；选座页面停留上限是在选座界面停留的时长，到达市场后会关闭选座页面重新打开，这是为了防止在选座页面呆的时间过长，锁座时会跳出一个韩文弹窗，而无法即使进入价格页，建议这个值设置8分钟以内。

4.提醒消息

当前有两种模式，进入价格选择页和点击seat selection completed，前者是进入锁票页面后电脑会响并发送消息提醒；后者是尝试点击seat selection completed按键时会响，主要区别是前者是确定锁票了，后者不一定，因为有极少部分客户反应点击seat selection completed后会出现各种各样的弹窗需要人为点击之后才会进入价格页，所以加了这个模式的区分功能。

如果大家平常在电脑前的话，建议使用seat selection completed，这种情况如果和对方冲突抢票了，即使你没有锁到票也会提醒你，这样你就知道这个区刚刚被人锁走了，那就可以着重刷这个区，因为他有概率过几分钟之后付款失败，票会回流到这个区里。

多浏览器同时刷——多开浏览器

大家如果想要一个号开多个浏览器进行刷可以按照下面操作（melon是支持这样操作的，可以提高效率）

大家如果需要开多个账号一起运行的话需要进行账号隔离（在一个窗口内打开的itp都是一个账号的），点击chrome个人头像，然后选下面的其他chrome个人资料出，点击不同的用户，比如下图中，如果我点击‘用户1’，他就会打开一个和我当前ga这个用户完全隔离的chrome浏览器；同理，你可以创建多个不同的窗口/无需登陆chrome账号

多开浏览器也会出现一个问题，因为melon是根据ip的请求频率来进行please try again的，所以多开浏览器会导致please try again频率提高；如果希望please try again频率不提高，可以看我在售的Melon Fleet程序，这个程序可以给每个浏览器分派专属ip，可以解决上述问题，这个程序相对会贵一些，更适合手上号多的人，或者是想大幅提高单号刷票效率的人。

远程控制与支付

有的时候人不在电脑边上，但也有可能刷到票；这种情况的话可以手机和电脑上装一个免费的todesk或者向日葵，从而实现手机远程操控电脑；这样的话人在外面，刷到票后手机会收到消息提醒，然后远程操控进行付款即可
